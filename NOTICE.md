## Ownership, authorship and proof of creation

GateQuake — the game, its client and server source, its art, audio,
level and economy design, and this documentation — was created by
GateQuake and is owned by GateQuake. Nothing here is derived from
another game's code or assets.

Authorship and creation dates are evidenced by a dated, cryptographic
record of the entire source tree. Every file is hashed with SHA-256 and
those hashes are combined into a single **root hash**. The root hash
reveals nothing about the code — a hash cannot be reversed — but any
copy of the work can be tested against it, and publishing it here dates
the whole body of work.

**Source tree as of 7 September 2026** (internal commit `ecebff660`,
379 files):

```
SHA-256 root: 2880ef1398c57246d1a42009a7c5f29c2d2f8cad8383b05f91df51276ef6792d
```

Method: SHA-256 of each tracked file; the lines `<sha256>  <path>`
sorted by path, joined with newlines, hashed again to give the root.
The per-file manifest is retained privately and can be produced if
ownership is ever disputed. Records are kept for each release, so the
history of the work is datable end to end, and the publication date of
this page is itself independently recorded by this repository's commit
history.
